Snake Duel

Embed elsewhere

Once this repo has a GitHub Pages deploy set up, embed this widget on any page with: 

<div id="snake-widget"></div>
<script src="https://michaelmocioiu.github.io/widget-lib/snake/dist/snake.js"></script>
<script>
  if (window.SnakeDuel?.mount) {
    window.SnakeDuel.mount(document.getElementById("snake-widget"));
  } else {
    console.error("SnakeDuel did not load. Check script URL and deploy path.");
  }
</script>
